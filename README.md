# 🏅 Olympics Athlete Analysis

## 📌 Project Overview

This project presents an Exploratory Data Analysis (EDA) of Olympic athlete data using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The objective of this project is to analyze athlete demographics, participation trends, medal distributions, and other patterns in Olympic data through data cleaning, statistical analysis, and visualization.

---

## 🎯 Objectives

- Analyze Olympic athlete participation.
- Understand athlete demographics such as age, height, and weight.
- Explore participation across different countries and sports.
- Analyze medal distributions.
- Identify trends and patterns in Olympic data.
- Create meaningful visualizations to communicate insights.

---

## 📂 Dataset

The dataset contains information about Olympic athletes and their participation in different Olympic events.

### Key Columns

- `Name` – Athlete name
- `Sex` – Athlete gender
- `Age` – Athlete age
- `Height` – Athlete height
- `Weight` – Athlete weight
- `Team` – Representing country/team
- `Sport` – Sport category
- `Event` – Olympic event
- `Medal` – Medal won by the athlete and etc.
